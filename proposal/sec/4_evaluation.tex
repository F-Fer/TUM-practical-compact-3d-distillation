\subsection{Benchmarks}

We will initially evaluate on 7-Scenes, DTU, and ScanNet++, following the protocols used by OTT3R~\cite{ott3r} and DéjàView~\cite{dejaview}. If resources permit, ETH3D~\cite{vggt} will be added to assess outdoor reconstruction. For camera pose estimation, we will also consider the Image Matching Challenge benchmark used by VGGT~\cite{vggt}.

\subsection{Metrics}

Geometry will be evaluated on point maps obtained by unprojecting the predicted depth maps with the estimated camera parameters. Following DéjàView~\cite{dejaview}, we will report Relative $\ell_2$ error and the inlier ratio after Sim(3) alignment. On DTU and ETH3D, we will additionally report reconstruction accuracy, completeness, and Chamfer distance following the VGGT and OTT3R evaluation protocols~\cite{vggt,ott3r}.

Camera pose estimation will be measured using AUC@3$^\circ$ and AUC@30$^\circ$, computed from rotation and translation angular errors as in DéjàView~\cite{dejaview}. Efficiency will be evaluated through parameter count, FLOPs including TTO, wall-clock runtime, and peak GPU memory on a single GPU~\cite{dejaview}.
