\subsection{Reconstruction via Distillation}
\begin{itemize}
    \item OTT3R \cite{ott3r}: extends Distill3R by distilling $\pi^3$ (959M) into a 102M student on 2 GPUs
    \begin{itemize}
        \item closest prior work, but purely feed-forward, without TTO
        \item zero-shot, its poses fail to align views on out-of-distribution scenes (7-Scenes completion 34.8\,cm vs.\ 2.0\,cm for the teacher); it closes the gap by retraining the student per domain (23\,h)
    \end{itemize}
    \item Multi-View 3D Reconstruction using Knowledge Distillation \cite{reconstructiondistillation}
    \item A survey on knowledge distillation: Recent advancements \cite{surveydistillation} \todo{(mostly for us)}
\end{itemize}
