A Claude Code session that survives disconnects: run it inside tmux on tum1. This command creates the session the first time and reattaches to it after that:

ssh -t tum1 'tmux new -A -s claude -c ~/dev/TUM-practical-compact-3d-distillation ~/.local/bin/claude'

- To detach and leave Claude running: press Ctrl-b, then d. Closing the terminal or losing WiFi has the same effect, because the session keeps running on tum1.
- To reconnect: run the same command again; it reattaches to the running session.
- If the session ever ends: start it again the same way and run /resume inside Claude to pick up the previous conversation.

One recommendation for the multi-hour benchmark runs: have Claude start each one in its own tmux session, for example tmux new -d -s bench "uv run scripts/run_bench.py ...", and not as a Claude background task. Background tasks stop when Claude exits, while a separate tmux session keeps running even if you restart Claude.
